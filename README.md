# Milano Psicomotricità — sito web

Nuovo sito statico di **Milano Psicomotricità** (neuropsicomotricità dell'età evolutiva, Via Sapri 9 e 34, Milano).

- HTML, CSS e JavaScript puri: nessuna build, nessuna dipendenza
- Design responsive, animazioni allo scroll, menu mobile, filtri servizi, modulo contatti che apre WhatsApp
- SEO: meta tag, Open Graph e dati strutturati schema.org

## Struttura

```
index.html      pagina unica
css/style.css   stili
js/main.js      interazioni
assets/         favicon
```

## Anteprima in locale

```bash
npx http-server -p 5391
```

Le foto delle sedi sono caricate dal sito attuale (`milanopsicomotricita.it/wp-content/uploads/...`): prima di dismetterlo, copiale in `assets/` e aggiorna i percorsi.
